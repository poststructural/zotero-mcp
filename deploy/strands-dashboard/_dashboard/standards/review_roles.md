# Review roles (GPT and Claude)

Austin chose this division on 2026-11-23 from the blind pilot votes (GPT with the corpus won 11–3; Claude's prose rewrites were mostly rejected).

**GPT (with the field corpus)** handles prose, paragraph shape and organization, following the rubric and Dorothea's standards first. When it spots an evidence, attribution, quotation or page problem, it flags it as a note (new = null), not a rewrite.

**Claude** handles the evidence pass:
- unsupported motives or findings;
- overclaims against the source;
- blurred attribution;
- quotations and pages, checked against the PDFs and `Corpus reports/quote_check_all_strands.md`;
- the accuracy of source-audit details (purpose, method, sample, findings, limits).

Claude writes rewrites only for evidence fixes. Every Claude suggestion names the source and page it rests on, or says [CHECK].
